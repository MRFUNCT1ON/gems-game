# Gems Game

"Gems Game" is a simple game built with HTML, CSS & JS that mimics a "Bejeweled" / "Candy Crush" style game, with crypto logos as the gems. This particular variant is designed for PulseMachinery, however gems and other variables are easily configured by editing `index.html`.
